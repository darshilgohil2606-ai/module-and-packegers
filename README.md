# Multi-Utility Toolkit

## Project Description
The Multi-Utility Toolkit is a menu-driven Python project that provides multiple useful operations in one application. It allows users to perform date and time operations, mathematical calculations, random data generation, UUID generation, file handling, and module exploration.

The project uses Python's built-in modules and custom modules to perform different tasks efficiently.

## Features

### 1. Datetime and Time Operations
- Display current date and time.
- Calculate the difference between two dates.
- Format dates in different formats.
- Stopwatch functionality.
- Countdown timer.

### 2. Mathematical Operations
- Calculate factorial of a number.
- Calculate compound interest.
- Perform trigonometric calculations (sin, cos, tan).
- Calculate the area of geometric shapes (Circle, Rectangle, Triangle, Square).
- Perform basic arithmetic operations (+, -, *, /, %).

### 3. Random Data Generation
- Generate random numbers.
- Generate random lists.
- Create random passwords.
- Generate OTPs.
- Select random samples from a dataset.
- Play a number guessing game.

### 4. Generate Unique Identifiers (UUID)
- Generate unique UUIDs.
- Generate Version 4 UUIDs.

### 5. File Operations
- Create new files.
- Write data into files.
- Read file contents.
- Append data to existing files.
- Store files in the project's `data/` folder.

### 6. Explore Module Attributes
- Explore built-in Python modules.
- Display available module attributes using `dir()`.

## Technologies Used
- Python 3
- Python Built-in Modules:
  - datetime
  - math
  - random
  - uuid
  - time
  - importlib
  - os
- Custom Python Modules

## How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone the project.
3. Open the project folder in VS Code or any Python editor.
4. Open the terminal.
5. Run the following command:

```bash
python main.py
```

6. Select an option from the main menu.
7. Follow the instructions displayed on the screen.
